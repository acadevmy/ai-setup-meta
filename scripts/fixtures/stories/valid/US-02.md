**User Story**
Come manager, voglio ripristinare un path archiviato, così da annullare una cancellazione fatta per errore.

**Acceptance Criteria**
**Scenarios**

**Scenario:** ripristino
**Dato** un manager nel cestino
**Quando** ripristina un path che ha archiviato
**Allora** il path torna nel catalogo

**Scenario:** ripristino non riuscito
**Dato** un manager che ha chiesto il ripristino di un path
**Quando** il ripristino fallisce
**Allora** viene avvisato dell'errore
**E** il path resta nel cestino

**Open points**
- Da confermare: un manager può ripristinare ciò che ha archiviato un editor?
